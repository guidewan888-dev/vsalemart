# VSaleMart — ถอดแบบทุกหน้าและดีไซน์ซิสเต็ม

หน้าหลังบ้านใช้ components/admin/admin-shell.tsx เดิม (หัว Seller Center, เมนู, สี และกรอบหน้าจอ) โดยเติมส่วนงานใหม่ผ่าน children. สินค้า ตัวเลือก รูปภาพ และประวัติ Shopee เชื่อมกับตารางเดิม.

## Foundations

Brand #EE4D2D; Action #C53618; Surface #FFFFFF; Canvas #F5F6F8; Text #22252B; Muted #636873; Success #13764D; Warning #996000; Danger #BE2636. Noto Sans Thai. Body 16px/1.65; labels 14px; metadata 12–13px. Content 1240px; radius 12px cards/8px controls; spacing 4/8/12/16/20/24/32/40px.

## สถานะร่วม

ทุกหน้าข้อมูลมี loading, empty, error และ retry/แก้ข้อมูลตามบริบท. ฟอร์มมี required validation, สถานะกำลังบันทึก และผลสำเร็จ/ผิดพลาด. หน้า private ตรวจ session และ API/RLS ตรวจสิทธิ์ซ้ำ. ปุ่มไม่พร้อมใช้งานปิดจริง. มือถือใช้กริดสินค้า 2 คอลัมน์ ฟอร์ม 1 คอลัมน์ ตารางเลื่อนแนวนอน เมนูหลังบ้านเดิมเป็น drawer.

## การเชื่อมและขอบเขตที่ยังต้องตั้งค่าก่อนเปิดจริง

Migration ใหม่ยังไม่ได้รันบนฐานข้อมูลจริงในเซสชันนี้. ตั้งสิทธิ์ staff, ข้อมูลร้าน/ภาษี/บัญชีรับเงิน/ขนส่ง, recovery redirect และตัวตั้งเวลาหมดออเดอร์ก่อนเปิด checkout. QR และบัตรยังไม่มี provider ตามข้อมูลจากเจ้าของร้าน จึงปิดจริง; คืนเงินและขนส่งเป็นงานพนักงาน. ไฟล์นี้ไม่ใช่หลักฐานว่าฐานข้อมูลจริงถูกเปลี่ยนหรือเว็บ production ถูกเผยแพร่แล้ว. ดู deployment-runbook.md.
